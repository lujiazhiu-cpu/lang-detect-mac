# 语种识别

macOS 菜单栏常驻语种识别 App，基于 Apple Vision + NaturalLanguage，完全离线免费。

## 功能

- 🖱️ 双击启动，常驻菜单栏
- ⌃⌥L 或点击菜单栏图标 → 截图框选区域
- 🔍 OCR 识别文字，自动判断语种（中/英/日/韩/法/德/乌克兰语等 20+ 语种）
- 📋 汇总弹窗显示识别结果，可选「查看详细标注」或「好的」关闭
- 🖼️ 详细标注图：每段文字标注颜色框 + 语种标签，**点击任意位置关闭**
- 🖥️ 多屏支持：弹窗跟随截图所在屏幕显示
- 📝 模糊/低置信度文字自动 fallback 猜测语种，减少「未识别」

## 安装

1. 下载 [语种识别_installer.dmg](../../releases/latest)
2. 打开 DMG，把「语种识别」拖入 Applications 文件夹
3. 双击 Applications 里的「语种识别」启动
4. 菜单栏出现图标即表示运行成功

> 首次启动 macOS 可能提示「无法验证开发者」，请在「系统设置 → 隐私与安全性」中点击「仍要打开」。

## 使用

- 按 `⌃⌥L`（Control + Option + L）或点击菜单栏图标，开始框选截图
- 识别完成后弹出汇总结果窗口
  - 点「查看详细标注」→ 打开标注图，点击任意位置关闭
  - 点「好的」→ 直接关闭

## 技术栈

- Swift（单文件，无依赖）
- Apple Vision Framework（OCR）
- Apple NaturalLanguage Framework（语种识别）
- macOS AppKit（菜单栏 + 窗口）

## 系统要求

- macOS 12 Monterey 及以上
- 无需安装额外依赖，完全离线运行
